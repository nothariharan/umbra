lever.py reexec replays the evidence run string verbatim and does not set SUBMIT_REV from the evidence rev field. Any recorded run that invokes evidence/verifier/run_s3_pytest.ps1 or run_s3_check.ps1 must embed SUBMIT_REV equal to the SUBMIT pin in that run string. Script default rev 475ca690ab88 is not acceptable for S3-CC2 reexec at pin 1d75850acf29. Preferred pattern: powershell -NoProfile -Command "$env:SUBMIT_REV='1d75850acf29'; & evidence/verifier/run_s3_pytest.ps1 -Node ..." (same for run_s3_check.ps1 -Check ...).
